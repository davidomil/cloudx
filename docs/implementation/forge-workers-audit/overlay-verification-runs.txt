[terminal-boundary-source-review]
NodePtyTerminalProcess ignores resize after its recorded exit event. Exact ENOTTY/EBADF ioctl race messages are ignored only for resize and do not set exited/quiescent state; other errors rethrow. CodexTerminalSession skips resize for a known closed terminal. Unexpected WebSocket input/resize errors are logged and close only the affected socket with 1011; listener cleanup exceptions are contained. Regression cases keep the same session/replay available and prove server health after actual PTY exit/stop. These behaviors are grounded in the production source and tests rather than treating a descriptor error as proof of process-tree termination.
